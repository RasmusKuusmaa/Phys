A plane wave, expanded in spherical coordinates around a scattering centre, is exactly
equivalent to an infinite sum of partial waves, one for each value of orbital angular
momentum quantum number l, each already an eigenstate of angular momentum. For a spherically
symmetric potential, angular momentum is conserved during scattering, so the potential
cannot mix different l values into each other — each partial wave scatters completely
independently of every other one, reducing a three-dimensional scattering problem to a set
of decoupled one-dimensional radial problems, one per l.

Far from a finite-range potential, each partial wave still looks like a free spherical wave,
but with its phase shifted by an amount delta_l relative to what it would have been with no
potential at all — the potential can only delay or advance each partial wave's phase, never
change its amplitude, since probability is conserved (nothing is absorbed) for a real,
non-absorptive potential. Every physical consequence of the scattering — the full
amplitude, the differential cross-section, the total cross-section — is built entirely out
of this set of phase shifts, one real number per l.

In practice only a finite number of partial waves matter for a given potential and energy: a
partial wave with angular momentum l corresponds classically to an impact parameter roughly
l/k, so once l/k grows past the potential's actual range, that partial wave barely samples
the potential at all and its phase shift approaches zero. This is why low-energy scattering
off a short-range potential is often dominated by just the l = 0 (s-wave) phase shift alone,
which is what makes phase-shift analysis practically tractable rather than requiring
infinitely many terms.
