A hypothesis test is built on a deliberately conservative starting assumption: the null hypothesis, usually the "boring" claim that nothing interesting is happening -- no difference between groups, no effect of a treatment, no association between two variables. The test doesn't try to prove this hypothesis; it asks a narrower question: if the null hypothesis were true, how likely would it be to see data as extreme as what was actually observed, just from ordinary sampling variability?

That likelihood is the p-value, and it is easy to misread because of how it's phrased. It is not the probability the null hypothesis is true -- it's the probability of the data (or more extreme data), computed under the assumption that the null hypothesis is already true. Flipping which side of that conditional probability you're asking about is a subtle but real error, and one of the most common misreadings of statistics in the applied sciences.

Because the p-value alone can't tell you the null hypothesis is definitely false, researchers fix a significance level in advance -- conventionally 0.05 -- as the threshold below which they'll treat the evidence as strong enough to reject the null hypothesis. This is a decision rule, not a certainty: setting that threshold creates two distinct ways to be wrong. A Type I error rejects a null hypothesis that's actually true (declaring an effect exists when it doesn't); a Type II error fails to reject a null hypothesis that's actually false (missing a real effect). These two error types trade off against each other -- making the threshold stricter to avoid false alarms (fewer Type I errors) necessarily makes it harder to detect real effects (more Type II errors), which is why choosing a significance level is a judgment call about which kind of mistake is more costly in a given context, not a purely mathematical decision.
