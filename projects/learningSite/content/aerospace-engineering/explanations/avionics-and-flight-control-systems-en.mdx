A conventional, purely mechanical flight control system connects the pilot's control stick to the ailerons, elevator, and rudder through cables, pulleys, and (on larger aircraft) hydraulic actuators the cables command directly -- move the stick, and the surface moves by a proportional amount, full stop. A fly-by-wire system breaks that direct chain: the stick becomes an electrical input device, flight-control computers read it alongside the aircraft's current sensed attitude, airspeed, and angle of attack, and the computers then command the actuators with whatever surface deflection actually achieves what the pilot's input means. The pilot still commands the maneuver -- roll rate, a pitch or angle-of-attack target -- the computer is simply now the thing deciding how much elevator or aileron deflection delivers it, and it can refuse to deliver a deflection that would carry the aircraft past a structural or aerodynamic limit, such as a maximum angle of attack or load factor. This capability, called flight envelope protection, has no purely mechanical equivalent -- a cable has no way to know the aircraft is approaching a stall.

Because the flight-control computers are now doing safety-critical work a cable used to do passively, a single computer failure would be unacceptable, so fly-by-wire aircraft run several independent computers in parallel, cross-checking each other's outputs and voting when they disagree, with dissimilar hardware and software in different channels specifically so a single design flaw cannot take down every channel at once. The autopilot sits one layer up from this: rather than one monolithic "autopilot" system, it is a set of independently-engageable modes -- heading hold, altitude hold, autothrottle, an approach mode that couples to a ground- or satellite-based navigation signal for a fully coupled approach and landing (autoland) -- that a pilot selects and combines according to the phase of flight, with the pilot remaining responsible for monitoring the aircraft even when every available mode is engaged.

All of this, from the flight-control computers to the pilot's own primary flight display, is fed by a shared sensor suite rather than any one all-knowing source. Air-data sensors (a pitot-static system) measure airspeed and altitude from dynamic and static air pressure; inertial sensors (gyroscopes for angular rate, accelerometers for linear acceleration) integrate their readings over time to track attitude and short-term position changes with no external signal required at all, which is how aircraft navigated accurately for decades before satellite navigation existed; and satellite navigation supplies an absolute position fix that keeps the inertial solution from slowly drifting. Each source covers exactly the gap the others cannot: inertial sensors have no absolute reference and drift over time, satellite navigation can be lost to terrain shadowing or jamming, and air-data sensors say nothing at all about orientation -- so the aircraft's actual state is always a fusion of all three, not a handoff between them.
