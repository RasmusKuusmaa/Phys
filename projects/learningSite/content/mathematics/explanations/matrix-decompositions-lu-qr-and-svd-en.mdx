Rather than manipulating an arbitrary matrix directly every time, it is often far more useful to factor it once into a product of matrices with special, easily exploitable structure. LU decomposition writes a matrix as the product of a lower-triangular matrix and an upper-triangular matrix, which converts the hard work of Gaussian elimination into two cheap triangular back-substitution steps. This matters enormously in practice: once a matrix has been factored this way, solving the same system again for a different right-hand side -- or solving many such systems in sequence -- costs only the cheap triangular substitutions each time, not a full repeat of the expensive elimination process.

QR decomposition writes a matrix as the product of an orthogonal matrix (whose columns are mutually perpendicular unit vectors) and an upper-triangular matrix, and it is the standard tool for solving least-squares problems -- fitting a line or curve to data that has more equations than unknowns -- numerically well. The naive approach to least-squares forms the so-called normal equations directly, but this squares the original matrix's condition number in the process, which can catastrophically amplify rounding error for matrices that are already even mildly ill-conditioned. QR decomposition solves the same least-squares problem through a sequence of numerically stable orthogonal transformations instead, never forming the normal equations at all, which is exactly why QR-based methods, not the normal-equations approach, are the standard used in serious numerical linear algebra software.

The singular value decomposition (SVD) is the most general and most powerful of the three. Unlike eigenvalue decomposition, which requires a square matrix, or an ordinary matrix inverse, which requires invertibility, the SVD is defined for absolutely any matrix -- square or rectangular, invertible or singular -- factoring it into two orthogonal matrices sandwiching a diagonal matrix of non-negative singular values. This single factorization reveals a matrix's true rank directly (the number of nonzero singular values), provides the best possible low-rank approximation to the matrix for any target rank (by keeping only the largest singular values and discarding the rest, the mathematical basis of many data-compression and noise-reduction techniques), and defines the Moore-Penrose pseudo-inverse, a genuine generalization of the matrix inverse that exists and is well-defined even for matrices that have no ordinary inverse at all.
