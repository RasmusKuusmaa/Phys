A vector is a tensor with one index, a scalar is a tensor with zero indices, and a matrix that represents a genuine linear map is a tensor with two — the pattern generalises to any number of indices. What actually earns something the name "tensor" is not how many indices it carries but how its components change when you switch coordinate systems: a tensor's components transform by a specific, predictable rule (contracting with the Jacobian of the coordinate change, once per index) that keeps the underlying geometric object — a length, a flux, a stress — the same regardless of which coordinates you used to describe it.

Curvilinear coordinates make this machinery unavoidable rather than optional. In Cartesian coordinates the basis vectors point the same way everywhere, so the usual formulas for gradient, divergence and curl need no correction. In polar or spherical coordinates the basis vectors themselves rotate as you move — the "radial" direction at one point is not parallel to the "radial" direction at another — so distances, areas and derivative operators all pick up extra factors that account for that rotation. The metric tensor is exactly the bookkeeping device that captures this: in polar coordinates, ds² = dr² + r²dθ² says a small step in the angular direction covers more actual ground the farther out from the origin you are.

Raising and lowering indices — turning a "covariant" component into a "contravariant" one and back — is a real operation performed by contracting with the metric tensor, not a notational nicety. In an orthonormal Cartesian basis the metric is just the identity, so the distinction is invisible and both kinds of component happen to have the same numerical value; the moment the basis is curvilinear (or genuinely curved), raising and lowering an index changes the number, and treating the two as interchangeable produces a wrong answer.
